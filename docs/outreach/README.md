# Off-page outreach kit (Phase 1)

The off-page authority/entity work is the real long-term lever for both Google and AI-engine visibility. This kit makes the highest-value pieces ready-to-run. See the strategy in [../SEO-GAMEPLAN.md](../SEO-GAMEPLAN.md) (§5 and §9).

| File | Use it to |
|---|---|
| [brand-kit.md](brand-kit.md) | Keep Detta's name, description, and category language **identical everywhere** so AI engines read one coherent entity. Copy these verbatim into every profile. |
| [roundup-target-list.md](roundup-target-list.md) | The validated list of "best debt tools" roundups to get named in — the #1 GEO move. |
| [pitch-template.md](pitch-template.md) | The exact, white-hat email to send roundup authors (+ correction script if you're mislabeled). |
| [pitch-log.md](pitch-log.md) | Audit trail — one row per pitch/submission. |
| [org-profile-README.md](org-profile-README.md) | Draft content + setup steps for the GitHub org profile panel. |

## Suggested order

1. **Claim the entity** (week 1): create LinkedIn / Crunchbase / X using `brand-kit.md`; publish the org profile README; set repo description/topics. Add each new URL to the site's `sameAs` array.
2. **Software directories** (week 1–2): AlternativeTo, G2, Capterra, TrustRadius — software category only, **zero** seeded reviews.
3. **Roundup campaign** (week 2+): work `roundup-target-list.md` Tier 1 → Tier 2 with `pitch-template.md`, logging each in `pitch-log.md`.

## Guardrails (every action)

- Self-help **software** framing always; never "debt settlement / relief / counseling."
- No fake/incentivized/insider reviews — anywhere.
- No payment or affiliate deals for placements or rankings.
- No outcome/savings claims; third-party-attribute any fee stats.
- Disclose material connections; disclose "I'm the founder" in the same comment on forums.
