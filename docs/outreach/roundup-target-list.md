## "Alternatives to debt settlement" angle (stronger fit — build this list out)

Detta's *cleanest* positioning fit is content about resolving/settling debt **yourself** vs. hiring a settlement company. Run these queries through ChatGPT, Perplexity, and Google AI Overviews, log what they cite, and add the named-author articles here:

- `how to settle debt yourself without a company`
- `alternatives to debt settlement companies`
- `DIY debt settlement`
- `do it yourself debt relief`

## How to keep this list alive

1. **Monthly:** re-run the queries above in ChatGPT / Perplexity / Google AI Mode; add any newly-cited roundup with a **named author** + an **update within ~12 months**. Drop dead or affiliate-only ("we rank ourselves #1") pages.
2. **Prioritize** by: does an AI engine actually cite it? → author reachable? → does Detta genuinely fit the list's criteria?
3. **Track outreach** in [pitch-log.md](pitch-log.md) — one row per pitch.

## Do / Don't

- ✅ Pitch only lists Detta **genuinely** fits; offer real value (accurate fact-checking, a free press login).
- ✅ Ask explicitly to be placed in the **self-help / DIY** category.
- ❌ Never pay for placement, offer affiliate deals, or imply sponsorship.
- ❌ Never let a list describe Detta as a debt-settlement/relief service — correct it politely if it does.
